# ✨ Hand Magic — Webcam Gesture Game

A Python-based game that lets you control magical abilities using real-time hand gestures captured through your webcam.

## 🎮 Features

- **Open Palm:** Shield
- **Pointing Finger:** Fire
- **Pinch Gesture:** Charge
- **Closed Fist:** Burst
- Real-time webcam hand tracking
- Interactive game interface

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- Pygame
- NumPy

## 🚀 How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the game folder.
4. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Start the game using the provided Windows launcher, or run the main Python file:

   ```bash
   python main.py
   ```

6. Allow webcam access and try the hand gestures!

## 💻 Requirements

- Windows computer
- Working webcam
- Python installation
- Required Python packages listed in `requirements.txt`
